# frontendTC2005B


## Instalación del proyecto

Primero, clona el repositorio y accede a la carpeta del proyecto:

```bash
git clone https://github.com/rodrikk834/backendTC2005B.git
cd backendTC2005B
```

Una vez dentro de la carpeta del proyecto, instala las dependencias necesarias:

```bash
npm install
```

Este comando instalará todas las dependencias especificadas en el archivo `package.json`.

## Ejecutar el proyecto

Para iniciar el servidor de desarrollo, ejecuta:

```bash
npm run dev
```

La terminal mostrará la dirección donde se está ejecutando el proyecto. Normalmente será:

```text
http://localhost:3000
```

Abre esta dirección en el navegador para acceder a la aplicación.

## Comandos principales

| Comando | Descripción |
|---|---|
| `npm install` | Instala las dependencias del proyecto |
| `npm start` | Inicia el servidor de desarrollo |
| `node -v` | Comprueba la versión de Node.js |
| `npm -v` | Comprueba la versión de npm |

## Inicio rápido

Si ya tienes **Node.js** instalado, únicamente necesitas ejecutar:

```bash
npm install
npm start
```
